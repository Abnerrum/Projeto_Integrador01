# Projeto_Integrador01

O **GoParty** é um projeto desenvolvido com foco no lazer e na diversão, centralizando informações de Bares e Restaures para diversos tipos de público. O projeto demonstra a integração de um front-end intuitivo com um back-and funcional e simples, todos feitos em Python.

---

## 🎉 Funcionalidades

- **Filtros:** Conta com filtros para Setores, Tipos de estabelecimentos e Ambientação
- **Roleta:** Com dúvida em qual lugar ir? Coloque na roleta e ela sorteará!
- **Localização e site:** Os estabelicimentos podem colocar sua localidade ([Google Maps](https://www.google.com/maps)) e suas Redes sociais e/ou sites próprios

---

## 🧑‍💻 Tecnologias Utilizadas

- **Back-end & Front-end:** [Python](https://www.python.org/) + [Streamlit](https://streamlit.io/)
- **Banco de Dado:** [JSON](https://www.json.org/json-en.html)
- **Ambiente:** Servidor intregado do Streamlit

---

## 🗂️ Estrutura do Projeto

- 'Homepage.py': Página inicial do site
- 'Encontre_aqui.py': Página responsável por buscas pelas cidades e filtros aplicados
- '**Pasta:** cities': Pasta com os códigos fontes de cada cidade
- '**Pasta:** dataBank': Bancos de Dados em JSON de cada uma das cidades
- 'functions.py': Ligação do banco de dados com o **Back-end**
- '__init__.py': Modularizador de pastas

## 🔧 Como Executar o Projeto

1. Certifique-se de ter o **Python 3** instalado.
2. Clone este repositório:
   ```bash
   git clone https://github.com/JohnDelf01/Projeto_Integrador01
3. Instale o framework Streamlit:
   pip install streamlit

4. Inicie o servidor:
   **Se em IDE's:**
   "streamlit run Homepage.py"
   **Senão:**
   "c:(Caminho)
   "streamlit run Homepage.py"
